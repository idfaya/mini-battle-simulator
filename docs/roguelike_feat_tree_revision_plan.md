# Roguelike Feat 树修订计划

本稿记录下一轮 Roguelike Feat 树修订方案，用于后续回写 `design/roguelike_feat_skill_fill_sheet.md` 与拆解实现任务。

- 当前已落地运行时与策划 SSOT 继续以 `design/roguelike_feat_skill_fill_sheet.md` 为准。
- 本稿只收敛下一轮明确要做的修订项，不维护历史对照。
- 修订原则是：保留 `R / T1 / T2 / B / J / C` 树结构，优先强化构筑分歧、压缩纯数值节点、限制额外出手乘法，并尽量不新增专用 runtime 字段。

## 1. 修订目标

- 强化 Lv10 capstone 的终局感，让 capstone 更像“玩法定型”而不是“大数值补丁”。
- 压缩 `伤害 +1d4`、`CD -1`、`AC +1` 这类同质化 `B` 节点，增加更多改变目标选择、触发条件和状态语义的节点。
- 统一减伤、额外攻击、弹射、印记兑现等高风险机制的作用域和上限，避免不同职业在 runtime 里各写一套特例。
- 尽量把可表达为 `A / B` 的节点从 `C` 下调，减少后续维护和测试矩阵。

## 2. 全局修订

### 2.1 减伤体系

- 牧师 `R 神恩庇护` 固定为：全队共享，每回合第一次有友军受到伤害时，本次伤害 `-1d6`。
- 圣武士守护线已改为 `神圣灵光` 光环语义，不再归入减伤体系。
- 牧师 `J 独立庇护` 作为高阶路线收束节点，不在中前期提供 per-unit 团队常驻减伤。
- `圣域祷言` 与 `神恩庇护` 同回合触发时不叠加，固定取较高值。

### 2.2 额外攻击与连锁上限

- 所有 `反击 / 连击 / 击杀追击 / 被动追打` 统一视为 `bonus_attack`。
- 同一来源每回合最多触发 `1` 次被动额外攻击。
- 同一角色每回合最多执行 `2` 次被动额外攻击。
- `chainCountDelta` 总增量封顶 `+2`。
- `cooldownDelta` 不能把主动技能压到 `CD1` 以下。
- `markPayoutPerRound` 对同一目标每回合最多兑现 `1` 次。

### 2.3 文案与作用域

- 所有“首次”类效果必须写清楚作用域：`每回合首次`、`每角色首次`、`每目标首次`、`每来源首次`。
- 所有来源绑定状态都统一声明：重复施加时是刷新持续时间还是覆盖旧来源。
- 所有减伤类效果都写清楚是否作用于 DOT、AOE、反噬、自损。

### 2.4 节点分布

- 每个职业最多保留 `3` 个纯数值 `B` 节点。
- `J` 节点优先承担“两条分支合流后产生新玩法”的职责，不再作为大号数值卡。
- `Capstone` 只做两类语义：
  - 改写主循环。
  - 极大强化胜场场景。

### 2.5 命名风格

- 同一路线内的成长节点优先使用统一梯度命名，减少“同一路线、不同话术”造成的识别成本。
- 推荐梯度为：`基础 -> 熟练 -> 精通 -> 大师`。
- `基础` 用于 `R` 或路线起点，`熟练` 用于早期强化节点，`精通` 用于中后段路线收束，`大师` 用于 capstone 级终局节点。
- 若某个效果属于明显的终局改写语义，例如改变结算时序、改变触发窗口、显著改写主循环，应优先并入 `大师` 节点，而不是单独拆成平行命名。

## 3. 战士 Fighter

### 3.1 总表

`Lv1` 固定获得 `战士训练` 与 `R 回气基础`。`Lv3` 自动接入 `T1 反击基础`，`Lv5` 自动接入 `T2 护卫基础`。战士的早期节奏先用 `回气` 稳住血线，再在中段获得 `反击`，高段进入 `护卫` 团队保护窗口。

| 节点 | 父节点 | 类型 | 效果 | 落点 |
| --- | --- | --- | --- | --- |
| `R 回气基础` | — | `R` | 获得 `回气`：回复 `1d10 + 体质修正` 生命，每场 `1` 次 | `grant low 核心主动` |

### 3.2 路线说明

- `回气线`：`回气基础 -> 回气熟练 -> 回气精通 -> 回气大师`，负责战士的早期续航与稳场。
- `反击线`：`反击基础 -> 反击熟练 -> 反击精通 -> 反击大师`，负责战士在 `Lv3` 后建立近战反制和时序压制。
- `护卫线`：`护卫基础 -> 护卫熟练 -> 护卫精通 -> 护卫大师`，负责战士在 `Lv5` 后接管团队承伤、接远程与投射物反弹。
- `连击系`：`连击基础 -> 连击熟练 -> 连击精通 -> 连击大师`，作为从 `回气基础` 外放出的进攻支线，负责主动出手后的追击与转火。

### 3.3 剔除旧节点

- 下列旧节点不再保留在新战士树中：`重斩`、`钢铁姿态`、`战斗节奏`。
- 这些节点的问题是过于通用，只提供平数值，不足以表达战士当前的四条构筑路线：`反击`、`护卫`、`连击`、`回气`。
- 旧护卫线命名也整体替换，不再使用：`护卫加深`、`守护连环`、`钢墙宗师`。
- 新树只保留统一命名后的节点：`回气基础/熟练/精通/大师`、`反击基础/熟练/精通/大师`、`护卫基础/熟练/精通/大师`、`连击基础/熟练/精通/大师`。

### 4.2 路线说明

- `连击线`：`连击基础 -> 连击熟练 -> 连击精通 -> 连击大师`，负责高频追打。
- `截脉线`：`截脉基础 -> 截脉延续 -> 截脉精通 -> 连击大师`，负责控制兑现并通过共享终局收束。
- `调息线`：`调息基础 -> 调息熟练 -> 调息精通 -> 调息大师`，负责保命与自我恢复。

### 4.3 修订说明

- `连环宗师` 不再继续叠加额外破例次数，改成“首次命中必连击”的稳定终局。
- `不动明王` 统一写成低血自动触发，避免“半场 1 次”这类不直观表述。
- `连击大师` 改为同时要求 `连击精通 + 截脉精通`，让武僧的控制线不再只是挂件路线。
- `调息大师` 改为要求 `调息精通`，让保命线也必须先完成中段成长。
- 武僧删去 `连击强袭`、`截脉凝意` 等纯数值挂件，把连击线的机动与命中收益收进 `连击影步`。
- 武僧节点主名已按 `连击/截脉/调息` 三条路线重命名，原风味名退到描述文本。

### 5.2 路线说明

- `伏击线`：`伏击基础 -> 伏击熟练 -> 伏击精通 -> 伏击大师`，负责单点收割。
- `处决线`：`处决基础 -> 处决穿行 -> 处决精通 -> 处决大师`，负责穿透后排。
- `闪避线`：`闪避基础 -> 闪避熟练 -> 闪避精通 -> 伏击大师`，负责反守为攻并通过共享终局收束。

### 5.3 修订说明

- `直觉反击` 统一更名为 `直觉破绽`，避免与真正的额外攻击语义混淆。
- `影杀` 从每场 `3` 次下调到每场 `2` 次，保留高潮感但避免残局连杀过度滚雪球。
- `伏击大师` 改为要求 `伏击精通 + 闪避精通`，让闪避线不再只停在辅助层。
- `处决大师` 改为要求 `处决精通 + 处决穿行`，让处决线也按 `基础 -> 熟练 -> 精通 -> 大师` 闭环。
- 盗贼删去 `伏击准头`、`伏击步法`、`处决熟练` 等平数值节点，把收益并回 `伏击熟练 / 伏击精通 / 处决精通`。
- 盗贼节点主名已按 `伏击/处决/闪避` 三条路线重命名。

### 11.3 修订说明

## 13. 落地顺序
