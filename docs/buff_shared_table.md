# Buff 实现对照表

> **项目**: Mini Battle Simulator
> **说明**: 逐 ID 对照 `config/data/buffs.json` 与当前运行逻辑，供程序 / 测试速查。策划规则总纲见 [`design/buff_system_design.md`](../design/buff_system_design.md)；按类型分组索引见该文档 §4–§6。共 **30** 条，与 `buffs.json` 同步。

---

## 表头说明

| 列名 | 说明 |
|------|------|
| `主类型` | 实现层分类：`GOOD / BAD / CONTROL` |
| `规则分类` | 面向设计表达：增益、减益、DoT、标记、软控、硬控、资源、姿态、光环 |
| `持续` | 若 `isPermanent = true` 则按「永久」理解；否则按配置回合数理解 |
| `叠层` | `不可叠`、`可叠 N 层`，以及对应的 `refresh` / `add` 语义 |
| `触发/读取` | `回合开始触发`、`添加/移除触发`，或「无内建效果，供外部逻辑读取」 |
| `当前效果/用途` | 当前工程里的真实用途 |
| `备注` | 实现差异、读取位置或联动关系 |

## 修改时同步检查

改 Buff 时不要只改本表，应同步：

- `config/data/buffs.json`
- `design/buff_system_design.md`（若涉及设计语义）
- `skills/buff_effect_registry.lua`
- `config/tables/buffs.lua`
- `skills/battle_skill_status.lua`
- `skills/skill_effect_registry.lua`
- `modules/battle_buff.lua`
- `modules/battle_attribute.lua`
