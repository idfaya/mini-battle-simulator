# MiniBattle 自动战斗目标选择

## 1. 设计目标

- 自动战斗下，每个职业的目标选择行为必须与其核心技语义对齐：只设计结算规则而不设计目标选择，会让职业手感失真。
- 目标选择采用简单打分模型，不做复杂前瞻搜索；职业差异通过权重项叠加在公共框架上，而不是另起独立 AI。
- 目标选择规则同时覆盖：
  - 敌方目标选择倾向
  - 友方施放对象选择倾向（仅牧师等支援职业涉及）
  - 何时保留主动技、何时立即释放

## 2. 通用打分模型

候选目标按以下基础项加权：

- `base_threat`：当前敌人的输出 / 控场威胁。
- `finish_bonus`：低血、半血、可击杀等收尾窗口。
- `class_synergy_bonus`：职业核心技对目标提供的额外联动加分。
- `marked_target_bonus`：已被本职业 / 队伍标记的目标。
- `buff_dispel_bonus`：携带关键正面状态、值得被驱散的目标。
- `easy_hit_bonus`：当前 AC / 抗性较低、命中转化率高的目标。

每个职业仅通过 `class_synergy_bonus` 调整自身倾向；若与公共框架冲突，把职业倾向做成对总纲简易 AI 的轻量修正，不要替换主框架。

## 3. 物理职业目标倾向

### 3.1 战士

- 主动出手时优先选择高威胁近战敌人。
- 准备进入护卫架势时，优先牵制会持续压前排的敌人。

### 3.2 武僧

- 优先攻击容易命中的目标，使 60% 概率的连击稳定转化为实际收益。
- 走 `影步连打` 分支时偏向后排目标。

### 3.3 盗贼

- 优先攻击已被牵制、已被控制或夹击成立的目标。
- 使用 `诡诈打击` 时，优先选择当前生命值不高于 `50%` 的目标。

### 3.4 游侠

- 若已存在自己的印记目标且仍存活，优先持续追击该目标。
- 若尚无印记，优先选择能存活至少 `1` 回合以上的高威胁目标。

### 3.5 圣骑

- `灵光` 线：作为常驻光环不依赖主动选目标，优先站在能覆盖最多友军的位置承压。
- `惩戒` 线：优先选择携带关键增益、需要驱散，或具备高威胁的敌人。
- `圣手` 线：自动作用于生命值最低的友军，AI 不需要额外打分。

### 3.6 野蛮人

- 主动出手时优先攻击高血量、适合持续压制的前排目标，确保狂暴窗口期间能稳定兑现增伤。
- `重击` 偏向能吃满暴击范围收益的目标；若敌方 AC 过高，则谨慎施放，避免 `AC -2` 的自损换不到有效输出。

## 4. 法系职业目标倾向

### 4.1 法师

- 普攻优先攻击高威胁前排、即将出手的敌人或高机动目标。
- `冻结新星` 优先在十字范围内能覆盖 `2` 名及以上敌人，或能命中已霜冻的高威胁目标时释放。
- `暴风雪` 优先在敌方仍有 `3` 名及以上存活单位、或场上有 `2` 名及以上已霜冻目标时释放。
- 场上已存在自己的霜冻高威胁目标时，优先持续压制该目标。

### 4.2 术士

- 普攻优先攻击尚未点燃的高威胁目标。
- `灰烬爆燃` 优先攻击已被点燃的目标。
- `烈焰风暴` 优先在敌方数量较多或场上已有 `2` 名及以上点燃目标时释放。
- 敌方仅剩单体高血量目标时，维持「点燃 -> 爆燃」的单点循环。

### 4.3 牧师

- 团队血线稳定时，普攻优先攻击高威胁敌人或不死 / 邪恶单位。
- `治愈之言` 优先施放给生命值最低或身上有关键负面状态的友军。
- `圣域祷言` 优先在己方多人半血或敌方准备爆发时释放，不作为长时常驻光环。
- 团队血量稳定且无紧急救场需求时，保留主动给下一次危险波峰。

### 4.4 邪术师

- 普攻优先攻击尚未带印记的高威胁目标。
- `雷链` 优先在敌方存在相邻或密集目标时释放，并优先命中已带印记目标。
- `雷暴` 优先在敌方人数较多或场上已存在多个印记目标时释放，维持「挂印记 -> 兑现印记」闭环。
- 单体残局中，维持「邪能冲击挂印记 -> 同目标兑现额外雷伤」的稳定循环。
