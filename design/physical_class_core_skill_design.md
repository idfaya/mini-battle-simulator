# 物理职业核心技设计稿

## 设计目标

- 本文档统一收敛当前物理职业的核心技设计，作为后续 `Feat -> Runtime Skill -> 5e Meta` 实现的规则源。
- 目标是在保留 D&D 5e 风味的前提下，对职业核心技做足够简化，使其适配当前自动战斗与轻量技能系统。
- 本文档按“低阶 / 中阶 / 高阶”三阶子职业方式拆解现有物理职业。
- 所有能力优先复用各职业的基础攻击母技能，避免另起独立伤害链。

## 总体原则

- 5e 核心公式保持不变：命中仍然采用 `d20 + hit bonus vs AC`，伤害仍然基于现有基础攻击链结算。
- 职业核心技优先通过以下方式表达差异：
  - 触发时机
  - 目标筛选
  - 命中前修正
  - 命中后附伤
  - 反应登记与后结算
- 自动战斗场景下，职业技能设计必须和目标选择倾向同时定义；只设计结算规则而不设计目标选择，会导致职业手感显著失真。
- 所有成长入口统一由 `Feat` 承载，后续落地时只使用 `grant_skill`、`modify_skill`、`replace_skill`。
- 每个物理职业都拆成三阶子职业，与 `class_system_design.md` §2.4 的技能槽一一对应：
  - `low`：启用 `basic_attack_slot` + `core_slot`（`1 普攻 + 1 核心被动`）
  - `mid`：在 `low` 基础上追加 `mid_slot`（`1 主动` 或 `1 被动`）
  - `high`：再追加 `high_slot`（改造后的旧大招或新设计的高阶能力）
- 高阶能力不强制要求保留原大招形态；可以改写成更适合自动战斗和总纲模板的主动或被动。
- 职业成长不写成固定战斗内等级，而应通过同职业进阶、装备与 Feat 链推进。
- `额外攻击`、`额外行动`、`命中后追击` 必须严格区分，避免实现时语义串线。

## 字段口径

- 本文档采用 `class_system_design.md` 作为 Class 层字段规则源。
- 本文档中的职业能力对象统一为 `Class 单位`，不再使用独立“角色”口径。
- 阶段字段统一使用 `promotion_stage`。
- `promotion_stage` 的数据值统一为：
  - `low`
  - `mid`
  - `high`
- 展示层可渲染为：
  - `低阶`
  - `中阶`
  - `高阶`
- 技能槽统一使用：
  - `basic_attack_slot`
  - `core_slot`
  - `mid_slot`
  - `high_slot`
- 槽位语义统一为：
  - `basic_attack_slot` = 基础出手技能
  - `core_slot` = 低阶核心能力
  - `mid_slot` = 中阶新增能力
  - `high_slot` = 高阶终局能力
- 职业卡只推动 `Class 单位` 获得或进阶，不直接提供等级提升。
- `等级` 只负责数值成长；`进阶` 只负责同职业阶段推进；`转职` 才改变 `class_id`。

## 母技能映射

- 战士：基础武器攻击
- 武僧：徒手打击
- 盗贼：基础武器攻击
- 游侠：远程基础攻击
- 圣骑：圣武打击
- 野蛮人：狂斧劈砍

## 三阶子职业结构

- 每个职业都拆成 `low -> mid -> high` 三段。
- 推荐结构：
  - `low`：建立职业辨识度，只启用 `basic_attack_slot + core_slot`
  - `mid`：在 `low` 基础上追加 `mid_slot`
  - `high`：在 `mid` 基础上追加 `high_slot`
- 推荐授予顺序：
  - 初始获得 `low`
  - 后续通过同职业进阶或关键 Feat 晋升到 `mid`、`high`
- 设计目的：
  - 开局立即建立职业辨识度
  - 中期补足职业差异和可观察联动
  - 后期补足高潮时刻和终结体验
  - 保持自动战斗下的技能结构可理解、可预测
  - 让高阶能力服务总纲，而不是反向改写总纲

## 一页结论

| 职业 | 核心技 | 一句话定义 |
| --- | --- | --- |
| 战士 | 反击 | 敌方对你发动近战攻击后，攻击结算后你会立刻回手一次。 |
| 武僧 | 连击 | 徒手打击命中后有 `50%` 概率对同一目标追加一次额外攻击。 |
| 盗贼 | 伏击 | 目标被牵制、被控制或夹击成立时，你的基础武器攻击命中后追加伤害。 |
| 游侠 | 猎人印记 | 每回合 `1` 次，基础武器攻击命中后给目标挂上唯一印记，并在本回合第一次对其造成伤害时追加追猎伤害。 |
| 圣骑 | 神圣庇护 | 友军每回合第一次受到伤害时，为其提供一次 `1d6` 减伤。 |
| 野蛮人 | 狂暴 | 完成基础攻击或受到攻击时自动进入 `狂暴`；状态不叠层，持续到下回合结束，期间受到物理伤害 `-2` 且所有攻击伤害 `+2`。 |

## 六职业三阶规格

### 战士

- 5e 画像：`primary_ability = str`，`spell_ability = none`，`armor_formula = heavy_fixed`，`save_proficiency = fort / will`。

| 阶段 | 能力包 | 规则定义 |
| --- | --- | --- |
| `low` | 基础武器攻击 | 对单体敌人进行一次标准近战武器攻击；严格复用 5e 基础武器攻击链。 |
| `low` | 反击 | 敌方对你发动近战攻击后，无论命中与否，都会在该次攻击结算后登记并执行 `1` 次基础武器反击；反击本身不会再次触发反击。 |
| `mid` | 护卫架势 | `CD3`，持续到你下回合开始；期间你自身 `AC +2`，且友军承受的近战攻击可改由你承担；敌方本次近战攻击结算后，你会对攻击者发动 `1` 次护卫反击。 |
| `high` | 不屈之风 | 一场战斗 `1` 次；生命值将降到 `0` 时改为免死，将本次伤害归零，立即恢复到 `50%` 最大生命值，并清除当前一切状态。 |

- 当前实现同层还存在 `动作激增`、`精准攻击`、`横扫攻击`、`额外攻击` 等附加分支；主线低阶核心仍然是 `反击`。

### 武僧

- 5e 画像：`primary_ability = dex`，`spell_ability = wis`，`armor_formula = unarmored_dex_wis`，`save_proficiency = fort / ref`。

| 阶段 | 能力包 | 规则定义 |
| --- | --- | --- |
| `low` | 徒手打击 | 对单体敌人进行一次标准徒手攻击；严格复用 5e 基础武器攻击链。 |
| `low` | 连击 | 徒手打击命中后有 `50%` 概率对同一目标追加 `1` 次额外攻击；该次额外攻击不再触发连击。 |
| `mid` | 震劲掌 | `CD3`，对当前目标执行 `1` 次徒手打击；若命中，再以你的 `spellDC` 对目标进行强韧豁免，失败则 `STUN 1` 回合。 |
| `high` | 明镜止水 | `CD3`，回复自身生命并清除 `Frozen / STUN / SILENT`；当前执行体复用了旧的调息时间线，治疗骰按技能等级取 `1d8+3 / 2d8+3 / 2d8+6`。 |

- 当前 `mid` 还存在 `影步连打` 分支：对任意目标发动徒手打击，若目标位于后排则额外造成 `1d8` 伤害。
- 当前 `high` 还存在 `连拳宗师`、`截脉宗师`、`无垢宗师` 三条额外攻击 capstone；`明镜止水` 是独立的高阶救场主动。

### 盗贼

- 5e 画像：`primary_ability = dex`，`spell_ability = none`，`armor_formula = light_11_dex`，`save_proficiency = ref`。

| 阶段 | 能力包 | 规则定义 |
| --- | --- | --- |
| `low` | 基础武器攻击 | 对单体敌人进行一次标准近战武器攻击；严格复用 5e 基础武器攻击链。 |
| `low` | 伏击 | 基础武器攻击命中后，若满足以下任一条件则追加 `1d6` 伤害：目标当前正在攻击他人、目标已被控制、或前排夹击成立；相关专精会继续叠加额外伤害骰。 |
| `mid` | 影袭处决 | `CD3`，先执行 `1` 次基础武器攻击，并强制将该次攻击视为满足伏击条件；若目标当前生命值不高于 `50%`，再额外追加 `2d6` 伤害。 |
| `high` | 直觉闪避 | 每回合第一次被攻击命中时，受到伤害减半；若同时持有 `生还者`，则在触发后令你的下一次基础武器攻击视为满足伏击条件。 |

- 当前 `mid` 还存在 `扰乱飞刃` 与 `穿行突刺` 两条分支：前者命中后排目标时令其 `AC -1`，后者稳定制造一次强制伏击窗口。

### 游侠

- 5e 画像：`primary_ability = dex`，`spell_ability = wis`，`armor_formula = light_12_dex`，`save_proficiency = ref / will`。

| 阶段 | 能力包 | 规则定义 |
| --- | --- | --- |
| `low` | 远程基础攻击 | 对单体敌人进行一次标准远程武器攻击；严格复用 5e 基础武器攻击链。 |
| `low` | 猎人印记 | 每回合 `1` 次，远程基础攻击命中后给目标施加唯一印记并覆盖自己此前的旧印记；印记持续当前回合与下一回合，你本回合第一次对该目标造成伤害时额外追加 `1d4` 追猎伤害。 |
| `mid` | 狩猎指引 | `CD3`，对当前目标执行 `1` 次远程基础攻击；若该目标已被你标记，则额外追加 `2d6` 伤害。 |
| `high` | 箭雨 | `CD4` 的独立高阶主动；施放时连续发动 `4` 次标准远程武器攻击，每次随机选择 `1` 名敌人；若同一次箭雨内再次命中同一目标，则该次伤害依次减半。 |

- 当前 `mid` 还存在 `暮影射击` 与 `缠绕箭` 两条分支：前者对后排目标额外 `1d8`，后者命中后以反射豁免失败施加 `冻结 1` 回合近似表达 `Restrained`。
- 当前 `high` 还存在 `影袭宗师` 与 `缚林宗师` 两条额外攻击分支。

### 圣骑

- 5e 画像：`primary_ability = str`，`spell_ability = cha`，`armor_formula = medium_capped`，`save_proficiency = fort`。

| 阶段 | 能力包 | 规则定义 |
| --- | --- | --- |
| `low` | 圣武打击 | 对单体敌人进行一次标准近战武器攻击；严格复用 5e 基础武器攻击链。 |
| `low` | 神圣庇护 | 当前实现为持续团队保护：友军每回合第一次受到伤害时，由持有该被动的圣骑提供 `1d6` 减伤；该逻辑不区分攻击来源，也不是仅作用于圣骑自身。 |
| `mid` | 破邪斩 | `CD3`，先执行 `1` 次基础武器攻击；若命中，再追加 `2d8` 光耀伤害，并驱散目标 `1` 个正面增益。 |
| `high` | 圣手 | `CD3`，自动选择生命值最低的友军，回复 `2d8+4` 生命，并清除 `Frozen / STUN / SILENT / Poison / Burn`。 |

- 当前 `mid` 还存在 `守护灵光` 分支：持续到你下回合开始，为我方全体提供 `AC +1` 且各自每回合第一次受击减伤 `1d6`。
- 当前 `high` 还存在 `裁决圣骑`、`慈光圣骑`、`圣域圣骑` 三条额外攻击 capstone；`圣手` 是独立的高阶救场主动。

### 野蛮人

- 5e 画像：`primary_ability = str`，`spell_ability = none`，`armor_formula = unarmored_str_con`，`save_proficiency = fort / will`。

| 阶段 | 能力包 | 规则定义 |
| --- | --- | --- |
| `low` | 狂斧劈砍 | 对单体敌人进行一次标准近战武器攻击；严格复用 5e 基础武器攻击链。 |
| `low` | 狂暴 | 每次完成一次基础武器攻击，或每次受到攻击时，若当前未在狂暴中则自动进入 `狂暴`；狂暴不能叠层，持续到下回合结束，每场战斗默认只触发 `1` 次；期间受到物理伤害 `-2`，且所有攻击造成伤害 `+2`。 |
| `mid` | 重击 | `CD2`，对当前目标发动一次强化近战攻击；施放后自身获得 `AC -2` 的短时破绽，且本次攻击暴击范围翻倍、力量加值翻倍。 |
| `high` | 不倦狂暴 | 保留低阶 `狂暴` 的触发条件、持续时间与增益效果，但取消“每场战斗只触发 `1` 次”的限制。 |

- 当前实现已不再维护“狂怒层数”资源；`不倦狂暴` 只负责移除低阶 `狂暴` 的战斗次数限制。

## 职业核心技

### 战士：反击

#### 职业核心技

- `反击` 的职业定位是站桩反打与近战压制。
- 当前实现采用“先登记、后结算”的反应语义，保证敌方动作先完成，再由战士回手。

#### 触发规则

- 触发条件：敌方对你发动一次近战攻击。
- 命中要求：按当前实现与技能描述，命中与否都应触发。
- 结算时机：在敌方本次攻击动作结算后，对攻击者执行 `1` 次基础武器攻击。
- 次数限制：不限制次数。
- 防递归规则：
  - 反击本身不能再次触发反击。
  - 护卫反击与普通反击都带运行时标记，避免互相递归。
  - 只有近战攻击会登记反击，远程与 DOT 不会进入这条链。

#### 目标选择倾向

- 主动出手时优先选择高威胁近战敌人。
- 若准备进入 `护卫架势`，优先牵制会持续压前排的敌人。

#### 数值口径

- 反击完全复用 `基础武器攻击`。
- 当前实现不附带额外伤害系数，强度主要来自触发频率。

#### 实现备注

- `反击` 与 `护卫反击` 共用排队后结算框架。
- `护卫架势` 的 `AC +2` 通过临时 buff 提供，不直接改写角色底数。

### 武僧：连击

#### 职业核心技

- `连击` 的职业定位是高频追打。
- 当前实现的额外攻击仍然走一次完整的徒手母技能结算，但被 `__inMonkCombo` 标记保护，避免继续触发下一层连击。

#### 触发规则

- 触发条件：`徒手打击` 命中目标后。
- 触发概率：固定 `50%`。
- 结算时机：当前命中结算后，对同一目标追加 `1` 次额外攻击。
- 次数限制：不限制次数。
- 防递归规则：
  - 连击追加攻击不会再次触发连击。
  - 追加攻击不会重新选目标。

#### 目标选择倾向

- 优先攻击容易命中的目标，确保 `50%` 概率追打能稳定转化为实际收益。
- 若走 `影步连打` 分支，则更偏向后排目标。

#### 数值口径

- 追加攻击复用正常徒手攻击伤害。
- 相关专精会继续叠加 `1d4`、强制追加连击或命中后回血，但都建立在这条额外攻击链上。

#### 实现备注

- `震劲掌` 与 `影步连打` 都先打一段徒手母技能，再叠控制或附加伤害。
- `明镜止水` 当前与旧 `调息自愈` 复用同一时间线，描述值与实际治疗骰仍需长期统一。

### 盗贼：伏击

#### 职业核心技

- `伏击` 的职业定位是抓取战场窗口，把命中转化成额外伤害。
- 当前实现已经明确落成三类触发条件，不依赖背刺朝向系统。

#### 触发规则

- 满足以下任一条件时触发：
  - 目标当前正在攻击其他单位。
  - 目标处于控制状态。
  - 目标位于前排且我方前排存活单位不少于 `2`，形成夹击。
- 结算方式：基础武器攻击命中后追加 `1d6` 伤害。
- 次数限制：不限制次数。
- 边界规则：
  - `影袭处决`、`穿行突刺`、`生还者` 都可制造强制伏击窗口。
  - `偷袭专精`、`处刑者`、`影舞者`、`夹击老手` 会继续向这次伏击叠加额外伤害骰。

#### 目标选择倾向

- 优先攻击已被牵制、已被控制或夹击成立的目标。
- 若使用 `影袭处决`，则优先选择当前生命值不高于 `50%` 的目标。

#### 数值口径

- 基础伏击为 `1d6`。
- `偷袭专精` 会提升到 `2d6`，其他高阶专精再继续叠加。

#### 实现备注

- 当前实现中的“牵制”是通过读取目标最近一次攻击记录来判断，而不是“本回合已被友军攻击过”。
- 文档与实现后续应统一使用 `牵制 / 控制 / 夹击` 这三类条件表述。

### 游侠：猎人印记

#### 职业核心技

- `猎人印记` 的职业定位是锁定单个猎物并持续追猎。
- 当前实现不是纯延后兑现，而是“上印记”和“印记附伤”可以在同一次命中里连续发生。

#### 触发规则

- 触发条件：`远程基础攻击` 命中目标后。
- 施加效果：若本回合尚未上过印记，则给目标施加唯一印记，并移除你对其他敌人的旧印记。
- 持有上限：同一名游侠同时只能维持 `1` 个自己的印记。
- 持续时间：当前回合与下一回合。
- 追加收益：你本回合第一次对该印记目标造成伤害时，额外追加 `1d4` 追猎伤害。

#### 目标选择倾向

- 若已有自己的印记目标仍存活，优先持续追击该目标。
- 若尚无印记，优先选择能存活至少 `1` 回合以上的高威胁目标。

#### 数值口径

- 基础追猎附伤为 `1d4`。
- `追猎技巧` 与 `印记专精` 会再各叠加 `1d6`。
- `精准射击` 会让你对自己印记目标的基础武器攻击命中 `+1`。

#### 实现备注

- 印记归属绑定到游侠自身，多游侠并存时互不覆盖。
- `狩猎指引` 只是对印记目标追加 `2d6` 的单体兑现，不是持续 `2` 回合的团队引导技。

### 圣骑：神圣庇护

#### 职业核心技

- `神圣庇护` 的职业定位是团队减伤托底。
- 当前代码实现比旧文案更强，它作用于友军而不是仅作用于圣骑自己。

#### 触发规则

- 触发条件：友军在本回合第一次受到伤害时。
- 结算时机：在伤害结算前直接减免本次伤害。
- 减伤数值：`1d6`。
- 次数限制：按当前实现是“每个友军每回合各享一次”，而不是“全队共享一次”。
- 叠加关系：若同时存在 `守护灵光`，两者会分别结算，当前实现允许双层减伤叠加。

#### 目标选择倾向

- 作为低阶核心被动，不依赖主动选目标。
- 若同时拥有 `破邪斩` 或 `守护灵光`，圣骑应优先站在能覆盖团队的位置承压。

#### 数值口径

- 当前基础值固定为 `1d6`。
- `重甲祷法` 另提供圣骑自身每回合第一次受击减伤 `1d6`，属于平行防线。

#### 实现备注

- 当前实现与旧设计稿在“是否只保自己”上存在明显口径漂移，应以后者服从代码。
- `圣手` 的净化范围当前明确包含 `Frozen / STUN / SILENT / Poison / Burn`。

### 野蛮人：狂暴

#### 职业核心技

- `狂暴` 的职业定位是把主动压制与挨打反扑都转化为短时强化窗口。
- 当前实现不再维护“怒气层数资源”，而是用一次性触发的强化态直接表达野蛮人的爆发节奏。

#### 触发规则

- 触发条件：
  - 完成一次 `狂斧劈砍` 后，若当前未在 `狂暴` 中，则自动进入 `狂暴`。
  - 每次受到攻击时，若当前未在 `狂暴` 中，则自动进入 `狂暴`。
- 状态叠加：`狂暴` 不能叠层，也不会在已激活期间重复刷新。
- 持续时间：持续到你的下回合结束。
- 次数限制：低阶 `狂暴` 每场战斗默认最多触发 `1` 次。
- 高阶强化：若已拥有 `不倦狂暴`，则移除上述战斗次数限制，但保留原触发条件与持续时间。

#### 目标选择倾向

- 主动出手时优先攻击高血量、适合持续压制的前排目标，确保 `狂暴` 窗口期间能稳定兑现增伤。
- `重击` 更偏向能吃满暴击范围收益的目标；若敌方 AC 过高，应谨慎施放，避免 `AC -2` 的自损换不到有效输出。

#### 数值口径

- `狂暴` 当前固定收益为：`受到物理伤害 -2`、`所有攻击造成伤害 +2`。
- `重击` 当前固定口径为：`自身 AC -2 / 暴击范围翻倍 / 力量加值翻倍`。
- `不倦狂暴` 不提高单次 `狂暴` 的数值，只改变触发次数约束。

#### 实现备注

- 当前实现已不再维护“狂怒层数”资源，也不存在“触发后清空怒气”的旧逻辑。
- `狂暴` 的减伤判定当前只拦物理伤害，不会误减法术或其他非物理来源。
- `重击` 的 `AC -2` 通过独立 `Buff` 承载，避免直接改写基础属性。
- `不倦狂暴` 当前只负责移除 `barbarianBerserkUsed` 的战斗次数限制，不额外改写低阶 `狂暴` 的触发窗口。

## 自动战斗目标选择总则

- 自动战斗目标选择应采用简单打分模型，而不是复杂前瞻搜索。
- 推荐基础打分项：
  - `base_threat`
  - `finish_bonus`
  - `class_synergy_bonus`
  - `marked_target_bonus`
  - `buff_dispel_bonus`
  - `easy_hit_bonus`
- 每个职业主要通过 `class_synergy_bonus` 调整自身倾向，不改公共框架。
- 若目标选择逻辑与职业核心技语义冲突，应优先把职业倾向做成对总纲简易 AI 的轻量修正，而不是另起一套独立 AI。

## 实现落点建议

- `design/`：以本文档为规则源，回写各职业 Build 文档。
- `class_system_design.md`：提供 `Class 单位`、`promotion_stage`、技能槽和成长职责的统一字段口径。
- `config/tables/feats.lua`：定义职业核心技对应的 Feat。
- `config/class_build_progression.lua`：决定同职业进阶、Feat 链与后续强化如何把职业推进到低阶 / 中阶 / 高阶。
- `config/class_build_progression.lua` 中的阶段推进必须直接对应 `promotion_stage = low / mid / high`。
- `skill_package_id` 的切换必须与 `basic_attack_slot / core_slot / mid_slot / high_slot` 的启用关系同步。
- `config/tables/skill_runtime.lua`：定义被动、命中后附伤、反应登记、标记等运行时语义。
- `config/tables/skill_meta.lua`：补齐 5e 口径与规则说明。
- `skills/`：实现各职业核心技的具体技能逻辑。
- `modules/`：只补必要的目标事件、回合标记和自动战斗目标评分支持。

## 风险与边界

- 战士 `反击`、武僧 `连击`、盗贼 `伏击` 都不限制次数，后续平衡应优先控制单次收益，不要反向削成无触发感。
- 游侠 `猎人印记` 当前会在“上印记的同一次命中”里立刻触发追猎附伤；若要改成下一次才兑现，需要同步修改运行时逻辑。
- 圣骑 `神圣庇护` 与 `守护灵光` 当前会双重结算减伤；若后续设计要改成“取高不叠加”，必须改 runtime，而不是只改文案。
- 武僧 `明镜止水` 当前复用了旧 `调息自愈` 时间线，`skills.json` 的治疗描述与实际治疗骰仍有漂移。
- 野蛮人当前已不再使用“狂怒层数 -> 满层触发”的旧资源模型；若后续想回到层数制，需同时重做文档、buff 与 runtime 判定链。
